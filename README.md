# ALA-WEBSITE

A modern, responsive website for the **Amari Leaver's Association** at Amari Christian Secondary School.

## Preview

Open `index.html` in a browser, or run a local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Technology

- Semantic HTML
- Custom responsive CSS
- No build tools or external dependencies

## Pages

- `index.html` — main website
- `home.html` — alternate home entry page
- `styles/style1.css` — shared styling
